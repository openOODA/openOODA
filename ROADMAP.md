# openOODA Master Roadmap & Goal TODO

> **Mandate:** Harden openOODA (`.oo`) into a sound, zero-theater, zero-external-dependency systems programming language across `@openOODA`, `@openOODA-core`, and `@openOODA-system`. Backwards compatibility is NOT required — every phase executes a clean break. Scientific & mathematical libraries remain inside `ooda-standard` and must be genuinely validated.
>
> **Triple Veto Law:** Every item below requires unanimous **`VERDICT: PASS`** from all three read-only adversarial subagents (`integrity-auditor`, `systems-architect`, and `ooda-domain-auditor`), plus green build/tests/determinism/`ooda-verify cycle`, version bump, annotated release tag, `@openOODA/catalog` + `@openOODA/install/versions.toml` sync, and GitHub push before being checked `[x]`.
>
> **Resilience Levels (L0–L4 — PACE Doctrine):**
> - **L0 — Fail-Fast Trap:** Immediate trap/abort on memory, bounds, capability, or contract invariant violations (`requires`, `RETGUARD`).
> - **L1 — Local Containment:** Typed `Result`/`?` error propagation, bounded retries with jittered backoff, timeouts, circuit breakers, and backpressure — zero unhandled panics across boundaries.
> - **L2 — Fault Isolation & Supervision:** Isolated actor/domain supervision trees, watchdogs, per-domain memory/CPU quotas, zero-leak reclaim, and bounded restarts.
> - **L3 — Graceful Degradation (PACE):** Explicit Primary → Alternate → Contingency → Emergency capability downgrade paths (airgap offline queue, GPU → CPU fallback, load-shedding, crash-safe WAL checkpoints).
> - **L4 — Contested-Environment Survival:** Signed attestation, polymorphic builds (`--morph-seed` / `--morph-stealth`), `SECRET:` zeroization, Blackbox hash-chained crash autopsy, and `with_cap` chaos/fault-injection proofs.
>
> **License & Public Hub:** Canonical license across all openOODA repositories is **`Apache-2.0 WITH LLVM-exception`** ([`LICENSE`](LICENSE), stamped onto each repository as phases release; see [`TRADEMARKS.md`](TRADEMARKS.md)). While `openOODA-*` component repos remain private, [`openOODA/openOODA`](https://github.com/openOODA/openOODA) is the sole public hub for issues, discussions, and private vulnerability reports ([`SECURITY.md`](SECURITY.md), [`THREAT_MODEL.md`](THREAT_MODEL.md)).
